📖 Как это сделать 🌐 Официальный сайт

🚀 Публикация за 5 шагов

Всё, что нужно, — аккаунт GitHub и этот файл.

1

Создайте репозиторий

Зайдите на github.com/new и создайте репозиторий с именем username.github.io, где username — ваш логин на GitHub.

2

Загрузите файлы

Нажмите «Add file → Upload files» и загрузите этот index.html (и другие файлы, если есть). Либо используйте git:

3

Включите GitHub Pages

В настройках репозитория перейдите в Settings → Pages. В разделе «Branch» выберите main и папку / (root). Нажмите Save.

4

Подождите минуту

GitHub автоматически соберёт и опубликует сайт. Статус можно увидеть во вкладке Actions.

5

Откройте сайт

Ваш сайт будет доступен по адресу https://username.github.io. Готово! 🎉

💻 Минимальный index.html

Достаточно даже такого файла, чтобы сайт заработал.

index.html
<!DOCTYPE html> <html lang="ru"> <head> <meta charset="UTF-8"> <title>Мой сайт</title> </head> <body> <h1>Hello, World!</h1> </body> </html>
💡

Совет: файл обязательно должен называться index.html — это стартовая страница, которую GitHub Pages открывает по умолчанию.

✅ Чеклист перед публикацией

Проверьте эти пункты, чтобы всё прошло гладко.

  • Файл называется index.html и лежит в корне репозитория.
  • Все пути к стилям, скриптам и картинкам — относительные (без C:\...).
  • Репозиторий публичный (для бесплатного тарифа).
  • Ветка называется main (или master — тогда выберите её).
  • GitHub Pages включён в Settings → Pages.
  • Вы подождали 1–2 минуты после сохранения настроек.
